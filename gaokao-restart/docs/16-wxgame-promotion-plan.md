# 任务 16：微信小游戏上线推广落地方案

## 1. 背景与目标

截至 2026-06-09，`gaokao-restart` 微信小游戏上线一周访问不足 200 人。当前优先目标不是直接扩大买量，而是先补齐微信内自然传播闭环，让玩家完成一局后愿意把结果发给同学、班群、家长或社交平台。

本方案围绕《重回高三人生模拟》的核心传播点：

- 高考后重开一次高三。
- 晒分数、晒录取学校、晒滑档或逆袭结局。
- 用天赋、分数、院校和志愿风险制造可比较结果。
- 让班群、同学圈和高考相关内容账号自然接力传播。

## 2. 阶段目标

### 2.1 第 1 周目标

- 累计访问从不足 200 提升到 1000 到 3000。
- 完成一局率达到 40% 以上。
- 结算页分享点击率达到 15% 以上。
- 每个分享带来的新增访问达到 0.3 以上。
- 找到 2 到 3 个有效种子渠道，例如班群、校园号、小红书笔记、视频号短视频。

### 2.2 第 1 个月目标

- 累计访问达到 10000 以上。
- 形成 3 套稳定素材模板：晒结果、挑战榜、情绪话题。
- 形成 1 套可持续运营节奏：每日内容、每周挑战、节点活动。
- 判断是否值得进入小额广告测试。

## 3. 核心判断

上线一周不足 200 人，优先排查三个问题：

1. 用户是否能在 2 分钟内跑完一局并看到有趣结果。
2. 结算页是否有强烈分享理由。
3. 分享出去后，新用户是否能一眼看懂并愿意点进来。

如果这三个问题没有解决，买量会把问题放大，不能真正带来留存和裂变。

## 4. 产品侧改造

### 4.1 结算页分享卡

结算页需要成为第一传播入口。分享卡应包含：

- 高考分数，例如 `642 分`。
- 录取结果，例如 `被 XX 大学录取`、`滑档警示`、`普通本科`。
- 结局档位，例如 `S / A / B / C / X`。
- 本局 3 个天赋。
- 一句挑战文案。

推荐分享标题：

- `我重开高三考了 642 分，被 XX 大学录取`
- `我重开高三，结果滑档了，你敢试一次吗？`
- `班群挑战：谁能重开进 985？`
- `高考后第一件事：重开一次高三`
- `我的高三天赋是夜自习战神，你会抽到什么？`

分享图建议结构：

- 顶部：`重回高三人生模拟`
- 中部大字：分数 + 录取学校 / 结局
- 下方：三个天赋标签
- 底部：`点击重开你的高三`

### 4.2 分享入口

必须有两个明确入口：

- 结算页主按钮：`晒出结果`
- 结算页次按钮：`再来一局`

不要把分享藏在菜单或小图标里。结算页的主动作应从“再来一局”调整为“晒出结果”，因为拉新阶段更需要传播。

### 4.3 结果稀有度

为结局增加可传播标签：

- `天选逆袭`
- `稳上 985`
- `志愿鬼才`
- `惊险上岸`
- `滑档警示`
- `复读回本`
- `平凡但上岸`

标签应出现在总结页和分享文案中，方便用户截图和转发。

### 4.4 快速体验

首局体验控制在 90 到 150 秒内：

- 首页一键开始。
- 天赋页默认候选足够有梗。
- 属性分配允许一键随机或推荐分配。
- 轨迹页保留 `自动跑完`。
- 结局页信息优先展示分数、学校、结局，不先展示长解释。

### 4.5 埋点指标

至少记录以下事件：

| 事件 | 说明 |
| --- | --- |
| `visit` | 进入小游戏 |
| `start_game` | 点击开始重开 |
| `select_talents_done` | 完成天赋选择 |
| `allocation_done` | 完成属性分配 |
| `finish_game` | 跑到结局 |
| `share_click` | 点击分享 |
| `share_success` | 分享成功回流可观测时记录 |
| `restart_game` | 再来一局 |

每个事件需要带：

- 渠道参数。
- 是否首次访问。
- 本局结局 ID。
- 分数区间。
- 是否录取到真实院校。
- 是否复读。

## 5. 渠道侧执行

### 5.1 种子用户

第一轮不做泛朋友圈，优先找可互动的小圈层：

- 高中同学群。
- 大学校友群。
- 家长群。
- 教师朋友。
- 高考志愿相关微信群。
- 本地升学交流群。

发送方式不要说“我做了个小游戏”，而要发挑战：

```text
我们班谁能重开上 985？我第一把滑档了。
微信小游戏搜：重回高三人生模拟
```

```text
高考后重开一次高三，我考了 612 分但志愿翻车。
你们试试能不能上岸。
```

```text
抽到“夜自习战神”直接起飞，抽到“志愿鬼才”太真实了。
班群挑战：谁能刷出最好学校？
```

### 5.2 短视频平台

优先平台：

- 视频号。
- 小红书。
- 抖音。
- B 站。

内容不要讲玩法说明，直接讲结果和情绪。

选题模板：

- `高考后第一件事：重开一次高三`
- `我用 20 点属性重开高三，最后被调剂了`
- `如果高三多一个天赋，你会选什么？`
- `物理组和历史组各重开一次，差距有多大？`
- `复读一年到底值不值？我在小游戏里试了 10 次`
- `志愿填报最怕什么？不是低分，是滑档`
- `我重开 20 次高三，终于上岸 985`

单条视频结构：

1. 前 3 秒给结果：`我重开高三，考了 642 分。`
2. 中间展示关键选择：天赋、属性、志愿风险。
3. 结尾给挑战：`你能不能刷出更好的学校？`

### 5.3 图文平台

适合小红书、公众号、朋友圈。

标题模板：

- `高考结束后，我在小游戏里重开了一次高三`
- `我以为能上岸，结果被志愿坑了`
- `这个高考模拟器把我整破防了`
- `抽到这 3 个天赋，高三人生直接改写`

图文结构：

1. 第一张图：结果卡。
2. 第二张图：天赋截图。
3. 第三张图：分数和学校。
4. 第四张图：一句吐槽或挑战。

### 5.4 KOC 合作

先找小号，不找大号。目标账号：

- 高考志愿号。
- 校园生活号。
- 学习自律号。
- 本地升学号。
- 复读经验号。
- 大学生日常号。

合作方式：

- 给账号专属挑战主题。
- 给账号专属渠道参数。
- 用结果截图做内容素材。
- 按访问和完成量复盘，不只看点赞。

可用主题：

- `安徽考生重开挑战`
- `复读一年值不值挑战`
- `志愿鬼才挑战`
- `985 逆袭挑战`
- `滑档警示挑战`

## 6. 微信内优化

### 6.1 名称与搜索词

小游戏名称、简介、分享标题中应覆盖用户会搜的词：

- 高考重开。
- 重回高三。
- 高考人生模拟器。
- 志愿模拟。
- 复读模拟。
- 滑档模拟。
- 985 / 211。

对外主文案建议：

```text
高考后，重开一次高三。
```

### 6.2 首页首屏

首屏必须 1 秒看懂：

- 标题：`重回高三人生模拟`
- 副标题：`抽天赋、分属性、冲高考、看你能上哪所大学`
- 主按钮：`开始重开`

如果小游戏包体和审核允许，首屏可展示一张结果样例：

```text
示例：673 分 · 稳上 985 · 志愿鬼才
```

### 6.3 群传播玩法

后续可以加轻量群挑战：

- 本周最高分挑战。
- 谁能抽到隐藏结局。
- 谁能最低分上岸。
- 谁能不复读进 985。

首版不必做复杂排行榜，先用分享文案和结果卡完成基础传播。

## 7. 广告测试策略

不要在当前阶段重仓买量。满足以下条件后再开始小额测试：

- 完成一局率大于 40%。
- 分享点击率大于 15%。
- 分享回流系数大于 0.3。
- 次日回访率有可观测基础。

小额测试预算建议：

- 第一次：100 到 300 元。
- 单日不超过 100 元。
- 每次只测一个变量：素材、定向或落地文案。

优先测试人群：

- 高考后学生。
- 高中生和大学生。
- 家长。
- 高考志愿、学习、自律、校园兴趣人群。
- 安徽或已有真实录取数据覆盖地区。

广告素材仍然使用结果卡，不使用泛游戏介绍。

## 8. 7 天执行排期

### Day 1：补传播闭环

- 完成结算页分享卡文案。
- 增加 `晒出结果` 按钮。
- 增加基础埋点。
- 给分享链接增加渠道参数。
- 产出 10 张结果截图。

验收：

- 玩家跑完一局能一键分享。
- 后台能看到访问、开始、完成、分享点击。

### Day 2：熟人种子扩散

- 找 20 到 50 个种子用户。
- 发 3 套不同挑战文案。
- 收集用户对标题、结果、时长的反馈。

验收：

- 当日新增访问超过 200。
- 至少 5 个群或朋友圈产生二次传播。

### Day 3：短视频首轮

- 发布 3 到 5 条短视频。
- 每条只讲一个结果或一个梗。
- 评论区引导搜索小游戏名称。

验收：

- 找到播放完成率较高的题材。
- 记录每条视频带来的访问变化。

### Day 4：图文首轮

- 发布 3 篇小红书或朋友圈图文。
- 每篇使用不同结果卡。
- 测试标题差异。

验收：

- 找到点击和收藏较高的标题。
- 收集用户最想晒的结局类型。

### Day 5：KOC 首轮

- 联系 10 到 20 个小号。
- 给 3 到 5 个账号发专属素材。
- 每个账号使用专属渠道参数。

验收：

- 至少 2 个账号愿意发布。
- 能区分不同账号带来的访问质量。

### Day 6：产品微调

- 根据数据优化首屏标题。
- 根据分享率优化结算页文案。
- 根据完成率优化首局节奏。
- 补充最有传播力的 5 到 10 个结局标签。

验收：

- 完成率和分享点击率至少一个指标明显提升。

### Day 7：复盘与第二轮扩散

- 复盘渠道、素材、用户路径。
- 保留有效素材，淘汰无效素材。
- 制定第二周主题挑战。

验收：

- 输出一份数据复盘。
- 明确第二周主推渠道和主推素材。

## 9. 30 天运营节奏

### 第 1 周：冷启动

目标是验证自然分享闭环，不追求大规模曝光。

重点：

- 分享卡。
- 熟人群。
- 结果截图。
- 第一批短视频。

### 第 2 周：内容放大

目标是找到稳定内容模板。

重点：

- 每天 2 到 3 条短视频。
- 每天 1 篇图文。
- 每周 1 个挑战主题。
- 继续找 KOC。

### 第 3 周：节点活动

目标是绑定高考节点和志愿节点。

可用主题：

- 查分前：`先模拟一次你的分数命运`
- 查分后：`真实分数和重开分数差多少`
- 志愿期：`模拟一次滑档风险`
- 录取期：`如果当年重填志愿会怎样`

### 第 4 周：广告小测

目标是判断是否值得付费放大。

前提：

- 自然渠道已有可复用素材。
- 分享率和完成率达标。
- 能按渠道参数看转化。

## 10. 素材清单

### 10.1 必备截图

- 首页截图。
- 天赋选择截图。
- 属性分配截图。
- 轨迹关键事件截图。
- 高分录取结局截图。
- 滑档结局截图。
- 普通本科结局截图。
- 复读逆袭结局截图。
- 志愿鬼才结局截图。
- 隐藏结局截图。

### 10.2 必备文案

结果型：

```text
我重开高三考了 642 分，被 XX 大学录取。
```

挑战型：

```text
班群挑战：谁能重开进 985？
```

情绪型：

```text
高考结束了，但我又被志愿填报创了一次。
```

话题型：


### 10.3 视频脚本模板

```text

转折：本来以为稳了，结果志愿风险爆了。
结尾：你试试能不能比我上得更好。
```

## 12. 风险与注意事项

- 不要把“高考焦虑”包装得过重，避免给考生制造压力。
- 不要承诺真实预测录取结果，定位为娱乐模拟。
- 涉及真实院校和分数线时，文案要避免误导。
- 分享文案不要诱导强制转发。
- 广告投放前先确认小游戏合规、素材合规和数据闭环。

## 13. 当前最高优先级

下一步只做三件事：

1. 实现结算页结果分享卡和分享按钮。
2. 增加基础渠道参数和核心漏斗埋点。
3. 准备 10 张结果图和 10 条短视频/图文文案，进行第一轮种子扩散。

完成这三件事后，再决定是否做 KOC 放大或小额广告测试。
