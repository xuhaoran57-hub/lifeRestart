## 4. 发现的问题

### 4.1 分科比例明显偏物理

物理类占 87.4%，历史类仅 12.6%。当前 `resolveSubjectTrack()` 的物理权重过强：

- `INT * 1.2`
- `STR * 0.35`
- `MNY * 0.25`

同时当前模拟里 `INT` 几乎必定触顶，导致绝大部分玩家被推向物理类。

### 4.2 历史类录取显著更强

历史类平均分 600.2，高于物理类 576.1；985 可达率 53.4%，211 实录率 23.6%。这说明历史类样本少但偏强，可能由分科公式筛选出高 `INT/SPR/VOL` 玩家造成。

### 4.3 211 可达率过高，实录率偏低

总体 211 可达率 79.0%，但 211 实录率只有 7.3%。这不是投档线问题，而是录取选择算法和 `highScoreLowAdmission` 诊断口径共同造成：

- `canReach211` 只要能达到最低 211 线就为真。
- 实际录取会按策略、超线区间和随机权重选学校，很多可达 211 的人被分配到普通本科。
- `highScoreLowAdmission` 因此高达 76.1%，诊断过于敏感。

### 4.4 属性触顶仍然严重

触顶率：

```txt
INT: 99.1%
STR: 84.1%
SPR: 2.3%
VOL: 3.1%
```

这会削弱属性差异，让分数集中在 550-609 区间，也会让分科公式被 `INT/STR` 主导。

### 4.5 结局覆盖不足且头部集中

结局覆盖 47/80，Top 5 占 61.0%。高频结局集中在事件链：

- 英语听力意外 14.8%
- 住校适应成功 12.9%
- 中考定位成功 12.7%
- 睡眠保护成功 12.7%

低频/未出现结局集中在：

- 顶尖分数线：清北、华五、强基等。
- 隐藏路线：志愿数据、章程、艺体、作文传奇等。
- 低分路线：复读、专科、民办本科等。

## 5. 优化建议

### 5.1 先调分科公式

建议目标：历史类 35%-45%，物理类 55%-65%。

可尝试：

```ts
scorePhysics = INT * 0.75 + STR * 0.25 + MNY * 0.2 + scienceEventBonus - riskPenalty
scoreHistory = SPR * 0.9 + VOL * 0.1 + INT * 0.65 + humanitiesEventBonus
```

并把随机扰动从 `1.4` 提高到 `2.0-2.8`，避免所有高 `INT` 玩家自动流向物理类。

### 5.2 降低 INT/STR 触顶

优先处理 `eventEffectScale`：

- `INT: 0.42 -> 0.30`
- `STR: 0.42 -> 0.32`
- 保持 `SPR/VOL` 不动或略增，让稳定性和志愿信息更有存在感。

也可以把 `INT/STR` 上限从硬 10 改成软上限，但这会牵动 UI 和分数公式，建议后置。

### 5.3 修正 highScoreLowAdmission 诊断

建议不要用“可达任意 211/985”判断高分低报，而改成：

- `canReach985` 且实际非 985。
- 或 `finalScore >= bestReachable211.minScore + 20` 且实际非 211。
- 或分数达到同科类 211 最低线 + 30 仍录入普通本科。

这样 `highScoreLowAdmission` 会从 76% 降到更有诊断意义的区间。

### 5.4 调整录取选择权重

当前可达 211 很多但实录 211 少，可适当提高高 `strategyScore` 对院校层级的权重：

- `prestigeWeight` 在冲刺/均衡策略下提高。
- 高 `HVOL` 玩家优先在可达 211/985 池内选，而不是和普通本科混池竞争。
- 保守策略仍可保普通本科，保留“高分低报”叙事空间。

### 5.5 增加低分和隐藏路线触发面

当前 `<500` 只有 0.4%，导致复读/专科/民办本科几乎没有空间。可以：

- 增加少量高风险负面事件的 `SCOREMOD/RSK` 影响。
- 给 `C/D` 结局降低部分条件门槛。
- 隐藏路线改为更多依赖特定事件链，而不是同时要求高分和稀有事件。
