# 平衡报告

测试日期：2026-04-30

## 1. 本轮目标

本轮按 `11-simulation-optimization-plan.md` 执行 5000 局优化：

- 降低结局和录取院校集中度。
- 扩充广西 2024 首选物理本科普通批样本线。
- 提高志愿风险、滑档和 B/D 档路线存在感。
- 复核 `INT/STR` 触顶问题。

## 2. 调整项

- 录取线从 31 条扩充到 307 条，仍使用广西 2024 首选物理本科普通批口径。
- 录取算法从确定性排序改为带权随机，保留分数利用率和院校层级偏好。
- 滑档改为概率模型，受 `HVOL/RSK`、志愿风险事件和稳健事件共同影响。
- 条件表达式支持 `ADM?[985]`、`ADM?[211]`、`ADMSCORE>=650`、`MARGIN>=20`、`SLIDE=1` 等录取 token。
- 结局条件迁移了一批录取强相关路线，并压低高频事件链优先级。
- 事件成长缩放中 `INT/STR` 从 `0.5` 调整为 `0.42`。

## 3. 验证命令

```bash
node gaokao-restart/tools/validate-content.mjs
node gaokao-restart/tools/simulate.mjs 5000
```

## 5. 仍需观察

- 结局覆盖从 50/80 基线改为 45/80，本轮没有达到 `>=62/80`；主要未命中集中在顶尖分数、隐藏路线和低分复读/专科路线。
- `INT/STR` 触顶率仍高，降低事件缩放后平均分稳定，但触顶问题未完全解决。
- 985 实录率略高于第一轮目标，211 实录率低于目标；院校池扩充后实际录取更分散，但层级分布还可继续调。
- `highScoreLowAdmission` 诊断偏高，后续可把“可达 211”从全样本口径改成更严格的高分低录口径。
