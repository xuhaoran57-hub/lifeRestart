# 平衡报告

测试日期：2026-05-07

## 1. 本轮目标

本轮按上一版 5000 局报告继续优化，但不再调整分科、分数公式和录取算法，重点只处理结局层：

- 降低高频事件结局的一票覆盖，减少 Top 5 结局集中。
- 放宽低分路线入口，让复读、专科、民办本科、高复等结局能被结算到。
- 提高隐藏 X 路线有效优先级，避免被普通 A/B/C 结局长期压住。
- 给强基路线提供小范围入口，不整体抬高分数。

## 2. 已调整项

- 收窄高频结局：
  - `中考定位成功`：提高 `VOL/HSCR` 门槛，降低 `RSK` 上限和优先级。
  - `住校适应成功`：增加 `SPR` 与低风险要求。
  - `睡眠保护成功`：增加 `SPR` 要求并降低优先级。
  - `英语听力意外`：增加 `RSK>=35`，降低优先级。
  - `手机上交奇效`、`调剂陌生专业`、`专业名误导` 二次收窄，避免成为新的大口袋。
- 放宽低分路线：
  - `复读一年再战` 改为低 `ADMSCORE` + 低 `VOL` 路线。
  - `专科王牌路线` 改为低分、非 211、未滑档路线。
  - `高复预备役` 改为低分、非 211、低中志愿路线。
  - `民办本科咬牙上` 绑定实际普通本科、低余量和家庭资源。
- 提高隐藏路线：
  - `志愿填报鬼才`、`艺体上岸`、`强基材料满格`、`志愿数据怪`、`招生章程猎人`、`专业洁癖的胜利`、`风险分层大师` 等提高有效竞争力。
  - `强基宣讲点醒`、`志愿三套预案`、`保专业上岸`、`三角比较最优解` 等降低触发门槛并提高优先级。
- 顶尖路线微调：
  - `强基入围翻盘` 从 `HSCR>=640 & VOL>=70` 调整为 `HSCR>=625 & VOL>=62`，并纳入 `综合评价意识`。

## 6. 仍需观察

- 顶尖分数路线仍稀缺：`640+` 只有 0.2%，清北、华五、顶尖 985 仍未出现。下一轮若要增强爽点，建议只给少数传说/史诗天赋或竞赛事件做定向分数突破，不要全局抬分。
- `保底院校守住` 成为新的 Top 1，但占比为 11.0%，暂未形成过度集中。
- `章程一行救命` 本轮仍未稳定出现，可能被 `招生章程猎人`、`保专业上岸` 等更高优先级路线分流；后续可按剧情偏好决定是否继续放开。

## 7. 下一轮建议

当前分科、录取风险、结局覆盖和头部集中都已达标。下一轮建议优先做事件属性系统专项优化，先解决 `INT/STR` 在结局阶段过容易触顶的问题，再考虑顶尖路线和结算解释。

专项压测口径：除常规随机初始外，增加 `5/5/5/5`、`7/7/3/3`、`8/8/2/2` 三组固定初始属性，用来观察高学力/高精力开局是否仍会被事件普遍推满。

| 指标 | 当前常规模拟 | 下一轮专项目标 | 说明 |
| --- | ---: | ---: | --- |
| INT 触顶率 | 57.8% | 常规 <10%，高开局 <25% | `INT=10` 允许出现，但不能成为普遍结局 |
| STR 触顶率 | 54.2% | 常规 <10%，高开局 <25% | `STR=10` 允许出现，但不能成为普遍结局 |
| 平均最终分 | 570.9 | >=555 | 避免为了压触顶把整体分数打穿 |
| 历史类占比 | 39.8% | 35%-45% | 分科结构保持稳定 |
| 结局覆盖 | 68/80 | >=58/80 | 不牺牲结局多样性 |
| Top 5 结局集中 | 41.0% | <50% | 不让事件属性调整重新制造大口袋结局 |

建议实施顺序：

- 拆分事件正负收益缩放，让 `INT/STR` 正向事件更弱、负向事件更有存在感。
- 给事件正向收益增加软上限衰减，尤其是 `INT/STR>=8` 后收益递减。
- 在事件抽取层降低增加 `INT/STR` 的事件概率，提高降低 `INT/STR` 的事件概率。
- 在 `tools/simulate.mjs` 增加固定初始属性压测模式，用专项口径验证高开局触顶率。
- 达标后再设计 2-3 个顶尖路线加速器，以及结算页“为什么命中这个结局”的解释。

## 8. 事件属性专项结果

本轮已完成事件属性系统专项优化：

- 事件效果拆分为正向/负向两套缩放。
- `INT/STR` 事件正向收益加入软上限衰减：
  - 当前属性 `>=7`：正向收益 `*0.85`
  - 当前属性 `>=8`：正向收益 `*0.65`
  - 当前属性 `>=9`：正向收益 `*0.45`
- `INT/STR` 负向事件不再被过度压低，负向影响比上一版更容易留下痕迹。
- 根据玩家实测反馈，撤销“事件成长天花板”和小数显示，不禁止 `INT/STR` 到 10。
- 随机事件抽取新增权重修正：增加 `INT/STR` 的事件降低出现率，降低 `INT/STR` 的事件提高出现率；当当前属性较高时，这个倾向更明显。
- UI 属性仍显示整数，但属性值向下取整，避免 `9.x` 被四舍五入显示为 `10`。
- `tools/simulate.mjs` 增加固定初始属性压测参数：

```bash
node tools/simulate.mjs 5000 --fixed-5
node tools/simulate.mjs 5000
node tools/simulate.mjs 3000 --fixed-allocation=7,7,3,3

```
