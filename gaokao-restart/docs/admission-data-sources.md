# 录取数据来源记录

最后更新：2026-04-30

## 当前默认口径

```txt
profileId: gx-2024-physics
年份：2024
生源省份：广西
科类：首选物理
分制：750
批次：本科普通批
```

当前版本先落一版可运行样本库，并在 5000 局优化中扩充到 307 条院校专业组投档线，覆盖：

- 顶尖 985：北京大学、清华大学、复旦大学、上海交通大学、浙江大学等。
- 常见 985/211：南开大学、天津大学、同济大学、厦门大学、中山大学、广西大学、四川大学、重庆大学、西南交通大学等。
- 区域本科和民办本科：广西科技大学、桂林电子科技大学、桂林理工大学、广西医科大学、广西师范大学、南宁师范大学、北部湾大学、柳州工学院等。

这不是完整志愿填报数据库。后续扩展时应继续按同一口径补齐更多专业组。

## 分数线来源

- 来源名称：广西招生考试院。
- 数据页：`https://www.gxeea.cn/view/content_624_30533.htm`
- 数据口径：广西 2024 年本科普通批院校专业组投档最低分数线，首选物理科目组。

当前 `admission-lines.json` 中每条记录都保存了：

- `sourceName`
- `sourceUrl`
- `sourcePublishedAt`

本轮扩表时，主数据口径仍以广西招生考试院发布页为准；当官方页面不便直接抓取时，允许参考标明来源为广西招生考试院的转载页面辅助录入，但记录字段仍保留官方来源名称和官方发布页 URL。

## 院校标签来源

院校的 `985/211/doubleFirstClass` 标签使用教育部公开名单口径维护：

- 985 工程学校名单：`https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html`
- 211 工程学校名单：`https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html`
- 第二轮双一流建设高校及建设学科名单：`https://www.moe.gov.cn/srcsite/A22/s7065/202202/t20220211_598710.html`

## 后续扩表规则

- 不跨省混用分数线。
- 不混用历史类、物理类、文科、理科。
- 同一学校可以有多个专业组，但 `profileId + universityCode + groupCode` 不能重复。
- 同校最低投档线只代表“可进该校某专业组”，不代表任意专业都能录取。
- 中外合作、专项计划、民族班、护理、预科等特殊专业组后续应增加 `lineType` 后再细分展示。
