# 高考重开模拟器策划案

## 1. 文档目的

本文档基于 [人生重开模拟器](/d:/测试/lifeRestart-main/design/game-design.md) 的既有框架，细化可落地的高考主题方案：


默认采用“短局循环 + 多周目积累 + 数据驱动配置”的设计原则，并补齐以下内容：

- 属性表
- 天赋方向
- 阶段事件
- 结局分档
- 可落到 Excel 的字段结构

## 2. 设计原则

### 2.1 目标

- 让玩家在有限决策中体验“不同出身、习惯、临场状态”对高考结果的放大效应。
- 让高考主题既有现实代入感，也保留模拟器品类需要的戏剧性和复玩动力。
- 尽量复用原项目的天赋、事件、条件表达式、结算、继承与成就系统。

### 2.2 元进度

- 重开次数 `TMS`：影响稀有天赋与稀有事件的出现概率。
- 已见事件 `EVT`：用于图鉴、隐藏链解锁和“见多识广”类天赋触发。
- 已拥有天赋 `TLT`：用于继承与收集率。
- 已解锁结局 `END`：用于解锁名人角色、主题皮肤或特殊开局。
- 成就数量 `ACHV`：用于提升高阶开局概率。

### 2.3 结算思路

高考主题不再以“死亡”作为主要结束条件，而是以“阶段完成”或“状态崩盘”结束。

- 正常结算：到达高考出分、志愿填报或录取节点。
- 提前结算：中途辍学、崩溃休学、转轨就业、艺体单招、出国申请失败等。
- 单局继承：从本局天赋或阶段特质中继承 1 个到下一局。

## 3. 方案 1：《高考重开模拟器》标准版

### 3.1 项目定位

标准版保留原作“按年龄推进”的核心节奏，将人生主题压缩为“学前启蒙到高考录取”的成长线。玩家从出生背景、学习习惯和家庭资源出发，在 18 年的升学路径中经历关键事件，最终获得高考结果与人生起点评价。

### 3.2 核心体验

- 用 3 个开局天赋和一轮属性分配，撬动 18 年的升学命运。
- 在学前、小学、初中、高中等阶段中不断累积优势或埋下问题。
- 体验“智力不等于结果，家庭资源、心态稳定、信息质量同样重要”。
- 通过多周目逐步解锁竞赛线、保送线、复读线、艺体线和隐藏逆袭线。

### 3.3 核心流程

1. 进入模式选择。
2. 选择标准版高考模式。
3. 抽取并选择 3 个天赋。
4. 分配初始属性点。
5. 从 3 岁开始按年龄推进至 18 岁。
6. 在关键年龄触发学段事件、家庭事件、考试事件和分支链。
7. 在 18 岁进行高考结算与志愿填报结算。
8. 获得结局、总评和可继承特质。
9. 解锁对应成就、角色或特殊天赋。

### 3.4 属性系统

#### 3.4.1 当前属性表

| 代码 | 名称 | 类型 | 建议初始范围 | 含义 | 备注 |
| --- | --- | --- | --- | --- | --- |
| AGE | 年龄 | 当前属性 | 3-18 | 当前成长阶段 | 按年推进 |
| INT | 学力 | 可分配 | 0-10 | 理解力、记忆力、刷题吸收效率 | 核心成绩属性 |
| STR | 精力 | 可分配 | 0-10 | 体能、睡眠质量、持续学习耐力 | 影响熬夜与高三续航 |
| MNY | 资源 | 可分配 | 0-10 | 家庭支持、补课资源、学校平台、信息环境 | 影响辅导与志愿信息 |
| SPR | 心态 | 默认 5 | 0-10 | 抗压、自信、情绪稳定度 | 高压事件重要门槛 |
| LIF | 状态值 | 当前属性 | 1-10 | 是否还能维持当前升学路径 | 低于 1 提前结算 |
| SCR | 分数潜力 | 派生 | 0-750 | 当前阶段对应的可转化考试实力 | 由多属性综合计算 |
| VOL | 志愿情报 | 派生 | 0-100 | 报考信息准确度与专业认知 | 主要在 18 岁前后生效 |

#### 3.4.2 派生属性建议

| 代码 | 名称 | 计算逻辑建议 | 用途 |
| --- | --- | --- | --- |
| HINT | 最高学力 | 局内最高 INT | 总评、结局判定 |
| HSTR | 最高精力 | 局内最高 STR | 总评、结局判定 |
| HMNY | 最高资源 | 局内最高 MNY | 总评、结局判定 |
| HSPR | 最高心态 | 局内最高 SPR | 总评、结局判定 |
| HSCR | 最高分数潜力 | 局内最高 SCR | 高考结果判定核心 |
| HVOL | 最高志愿情报 | 局内最高 VOL | 志愿逆袭和滑档判定 |
| RSK | 风险值 | 由负面事件累计 | 用于崩盘、复读或临场失常 |

注：`HSCR` 和 `VOL` 是高考主题最值得新增的两个派生指标。前者负责“能考多少”，后者负责“能报多好”。

#### 3.4.3 总评规则建议

总评 `SUM` 建议由以下部分组成：

- `HSCR * 0.45`
- `(HINT + HSTR + HMNY + HSPR) * 8`
- `VOL * 0.8`
- 关键成就加成
- 特殊结局修正值

这样可以避免总评完全等于高考分数，让“保送、强基、志愿逆袭、复读翻盘”也有独立价值。

### 3.5 天赋系统

#### 3.5.1 天赋方向

标准版天赋建议分为 6 类：

| 类别 | 设计目的 | 示例方向 |
| --- | --- | --- |
| 家庭背景类 | 决定早期资源和环境差异 | 重点学区、县城中学、教师家庭、独生子女 |
| 学习禀赋类 | 决定长期成长曲线 | 学前启蒙、偏科怪才、记忆宫殿、理综脑 |
| 习惯人格类 | 决定稳定性与风险 | 自律、拖延、逢考失眠、抗压体质 |
| 社会关系类 | 决定老师同学和家庭互动 | 班主任赏识、家长期望过高、同桌学霸 |
| 赛道机会类 | 打开特殊升学路径 | 竞赛体质、艺体特长、英语优势、保送苗子 |
| 黑天鹅类 | 增加戏剧性和重开欲 | 临场超常、押题圣体、家庭变故、信息闭塞 |

#### 3.5.2 天赋示例池

| 名称 | 稀有度 | 描述 | 效果方向 |
| --- | --- | --- | --- |
| 学前启蒙 | 1 | 你比同龄人更早建立学习习惯 | 5 岁 `INT+2` |
| 重点学区房 | 2 | 你从小接触到更强的教育资源 | `MNY+2`，小学阶段高质量事件权重提升 |
| 县中黑马 | 1 | 环境一般，但你特别能卷 | 初中后 `INT` 成长事件权重上升 |
| 偏科怪才 | 1 | 数理极强，语文发挥不稳 | `INT+2`，高考稳定度下降 |
| 自律成瘾 | 2 | 你对计划表有近乎病态的执行力 | `STR+1`，关键节点 `INT` 成长提高 |
| 逢考失眠 | 0 | 平时还行，越到大考越容易崩 | 高考前 `SPR-3` |
| 班主任偏爱 | 1 | 老师愿意给你更多关注和机会 | 校内竞赛、推荐资格权重提升 |
| 家长期望过高 | 0 | 你的家总是把“别人家孩子”挂在嘴边 | `SPR-1`，但部分努力事件权重提升 |
| 竞赛体质 | 2 | 你特别适合在竞赛体系里出成绩 | 竞赛事件触发率提升，可通往保送链 |
| 艺体特长 | 1 | 你有一条不完全依赖文化课的路径 | 开启艺考 / 体育单招结局 |
| 押题圣体 | 3 | 你总能诡异地贴近考试重点 | 高考阶段额外分数加成 |
| 信息闭塞 | 0 | 你对选科、竞赛、报考规则总慢半拍 | `VOL-20` |
| 志愿军师 | 2 | 你身边有人很懂报考策略 | `VOL+35` |
| 少数民族加分 | 1 | 你在录取政策上有天然优势 | 高考结算修正加分 |
| 佛脚战神 | 1 | 平时一般，冲刺期提升极快 | 17-18 岁 `INT` 成长翻倍 |

#### 3.5.3 天赋互斥建议

- `重点学区房` 与 `县中黑马`
- `自律成瘾` 与 `重度拖延`
- `竞赛体质` 与 `全面均衡`
- `艺体特长` 与 `保送苗子`
- `志愿军师` 与 `信息闭塞`

#### 3.5.4 天赋继承建议

继承对象建议更偏“长期形成的能力”而非“出身设定”，例如：

- 可继承：自律、抗压、竞赛经验、信息意识
- 不建议继承：学区房、家庭背景、政策身份

### 3.6 阶段事件设计

#### 3.6.1 阶段划分

| 阶段 | 年龄 | 目标 | 主要事件类型 |
| --- | --- | --- | --- |
| 学前期 | 3-5 | 建立学习兴趣与家庭底色 | 启蒙、亲子互动、健康、早教 |
| 小学期 | 6-11 | 基础能力形成 | 成绩、老师评价、兴趣班、同伴关系 |
| 初中期 | 12-14 | 分流与自我认知 | 月考排名、重点班、青春期波动、竞赛初露 |
| 高一期 | 15 | 适应新环境与选科 | 分班、住校、偏科问题、社交变化 |
| 高二期 | 16 | 路线定型 | 竞赛、强基、艺考、补课、家庭压力 |
| 高三期 | 17 | 压力累积与冲刺 | 模考、失眠、逆袭、老师谈话、情绪波动 |
| 出分填报期 | 18 | 结果兑现 | 高考、估分、出分、志愿、录取 |

#### 3.6.2 每阶段重点事件包

学前期事件方向：

- 父母是否重视教育
- 是否形成阅读、专注和作息习惯
- 早教资源投入与效果偏差
- 搬家、转学、家庭结构变化

小学期事件方向：

- 第一次考高分或考砸
- 被老师夸奖、被同学排挤
- 奥数班、英语班、书法班、补习班
- “小镇做题家”意识萌芽

初中期事件方向：

- 进入重点班或普通班
- 碰到强对手后开始内卷
- 青春期分心、早恋、沉迷游戏、手机管理
- 第一次大型排名焦虑

高一期事件方向：

- 选科决策是否匹配个人优势
- 寄宿生活对精力与心态的冲击
- 发现周围天才太多后的自我怀疑
- 班主任、教练、补课老师带来的路线变化

高二期事件方向：

- 竞赛集训、强基计划、艺考培训
- 家庭经济压力爆发
- 成绩平台期
- 一次模考改变自我定位

高三期事件方向：

- 一轮复习提分、二轮瓶颈、三轮押题
- 模考超常或失常
- 熬夜与状态值消耗
- 家长、老师、同学对心态的干预
- 临近高考的崩溃或顿悟

出分填报期事件方向：

- 估分偏差
- 高考超常发挥 / 临场失误
- 志愿冲稳保策略
- 被调剂、滑档、捡漏
- 服从调剂与城市优先的价值冲突

#### 3.6.3 关键事件链建议

1. 县中逆袭链  
学前资源一般 -> 小学成绩突出 -> 初中重点班 -> 高中遇强更强 -> 高考逆袭 985 / 清北边缘

2. 竞赛保送链  
数理特长 -> 竞赛教练注意 -> 省队 / 国奖 -> 保送或强基

3. 心态崩盘链  
家长期待过高 -> 多次排名波动 -> 高三失眠 -> 临场失常 -> 复读或转轨

4. 志愿翻车链  
分数足够 -> `VOL` 不足 -> 冲得过高 -> 滑档 / 被不喜欢专业录取

5. 低分逆袭链  
分数一般 -> `VOL` 极高 -> 地域 / 专业判断正确 -> 实际结果优于同分段

- 风险值 `RSK`
- 关键事件是否触发
- 特殊路线标签
