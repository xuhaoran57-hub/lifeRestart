# 高考重开模拟器策划案

## 1. 文档目的

本文档基于 [人生重开模拟器](/d:/测试/lifeRestart-main/design/game-design.md) 的既有框架，细化两个可落地的高考主题方案：

- 方案 1：《高考重开模拟器》标准版
- 方案 2：《高三 365 天重开模拟器》冲刺版

两个方案都默认采用“短局循环 + 多周目积累 + 数据驱动配置”的设计原则，并补齐以下内容：

- 属性表
- 天赋方向
- 阶段事件
- 结局分档
- 可落到 Excel 的字段结构

## 2. 共用设计原则

### 2.1 共用目标

- 让玩家在有限决策中体验“不同出身、习惯、临场状态”对高考结果的放大效应。
- 让高考主题既有现实代入感，也保留模拟器品类需要的戏剧性和复玩动力。
- 尽量复用原项目的天赋、事件、条件表达式、结算、继承与成就系统。

### 2.2 共用元进度

- 重开次数 `TMS`：影响稀有天赋与稀有事件的出现概率。
- 已见事件 `EVT`：用于图鉴、隐藏链解锁和“见多识广”类天赋触发。
- 已拥有天赋 `TLT`：用于继承与收集率。
- 已解锁结局 `END`：用于解锁名人角色、主题皮肤或特殊开局。
- 成就数量 `ACHV`：用于提升高阶开局概率。

### 2.3 共用结算思路

高考主题不再以“死亡”作为主要结束条件，而是以“阶段完成”或“状态崩盘”结束。

- 正常结算：到达高考出分、志愿填报或录取节点。
- 提前结算：中途辍学、崩溃休学、转轨就业、艺体单招、出国申请失败等。
- 单局继承：从本局天赋或阶段特质中继承 1 个到下一局。

## 3. 方案 1：《高考重开模拟器》标准版

### 3.1 项目定位

标准版保留原作“按年龄推进”的核心节奏，将人生主题压缩为“学前启蒙到高考录取”的成长线。玩家从出生背景、学习习惯和家庭资源出发，在 18 年的升学路径中经历关键事件，最终获得高考结果与人生起点评价。

### 3.2 核心体验

- 用 3 个开局天赋和一轮属性分配，撬动 18 年的升学命运。
- 在学前、小学、初中、高中等阶段中不断累积优势或埋下问题。
- 体验“智力不等于结果，家庭资源、心态稳定、信息质量同样重要”。
- 通过多周目逐步解锁竞赛线、保送线、复读线、艺体线和隐藏逆袭线。

### 3.3 核心流程

1. 进入模式选择。
2. 选择标准版高考模式。
3. 抽取并选择 3 个天赋。
4. 分配初始属性点。
5. 从 3 岁开始按年龄推进至 18 岁。
6. 在关键年龄触发学段事件、家庭事件、考试事件和分支链。
7. 在 18 岁进行高考结算与志愿填报结算。
8. 获得结局、总评和可继承特质。
9. 解锁对应成就、角色或特殊天赋。

### 3.4 属性系统

#### 3.4.1 当前属性表

| 代码 | 名称 | 类型 | 建议初始范围 | 含义 | 备注 |
| --- | --- | --- | --- | --- | --- |
| AGE | 年龄 | 当前属性 | 3-18 | 当前成长阶段 | 按年推进 |
| INT | 学力 | 可分配 | 0-10 | 理解力、记忆力、刷题吸收效率 | 核心成绩属性 |
| STR | 精力 | 可分配 | 0-10 | 体能、睡眠质量、持续学习耐力 | 影响熬夜与高三续航 |
| MNY | 资源 | 可分配 | 0-10 | 家庭支持、补课资源、学校平台、信息环境 | 影响辅导与志愿信息 |
| SPR | 心态 | 默认 5 | 0-10 | 抗压、自信、情绪稳定度 | 高压事件重要门槛 |
| LIF | 状态值 | 当前属性 | 1-10 | 是否还能维持当前升学路径 | 低于 1 提前结算 |
| SCR | 分数潜力 | 派生 | 0-750 | 当前阶段对应的可转化考试实力 | 由多属性综合计算 |
| VOL | 志愿情报 | 派生 | 0-100 | 报考信息准确度与专业认知 | 主要在 18 岁前后生效 |

#### 3.4.2 派生属性建议

| 代码 | 名称 | 计算逻辑建议 | 用途 |
| --- | --- | --- | --- |
| HINT | 最高学力 | 局内最高 INT | 总评、结局判定 |
| HSTR | 最高精力 | 局内最高 STR | 总评、结局判定 |
| HMNY | 最高资源 | 局内最高 MNY | 总评、结局判定 |
| HSPR | 最高心态 | 局内最高 SPR | 总评、结局判定 |
| HSCR | 最高分数潜力 | 局内最高 SCR | 高考结果判定核心 |
| HVOL | 最高志愿情报 | 局内最高 VOL | 志愿逆袭和滑档判定 |
| RSK | 风险值 | 由负面事件累计 | 用于崩盘、复读或临场失常 |

注：`HSCR` 和 `VOL` 是高考主题最值得新增的两个派生指标。前者负责“能考多少”，后者负责“能报多好”。

#### 3.4.3 总评规则建议

总评 `SUM` 建议由以下部分组成：

- `HSCR * 0.45`
- `(HINT + HSTR + HMNY + HSPR) * 8`
- `VOL * 0.8`
- 关键成就加成
- 特殊结局修正值

这样可以避免总评完全等于高考分数，让“保送、强基、志愿逆袭、复读翻盘”也有独立价值。

### 3.5 天赋系统

#### 3.5.1 天赋方向

标准版天赋建议分为 6 类：

| 类别 | 设计目的 | 示例方向 |
| --- | --- | --- |
| 家庭背景类 | 决定早期资源和环境差异 | 重点学区、县城中学、教师家庭、独生子女 |
| 学习禀赋类 | 决定长期成长曲线 | 学前启蒙、偏科怪才、记忆宫殿、理综脑 |
| 习惯人格类 | 决定稳定性与风险 | 自律、拖延、逢考失眠、抗压体质 |
| 社会关系类 | 决定老师同学和家庭互动 | 班主任赏识、家长期望过高、同桌学霸 |
| 赛道机会类 | 打开特殊升学路径 | 竞赛体质、艺体特长、英语优势、保送苗子 |
| 黑天鹅类 | 增加戏剧性和重开欲 | 临场超常、押题圣体、家庭变故、信息闭塞 |

#### 3.5.2 天赋示例池

| 名称 | 稀有度 | 描述 | 效果方向 |
| --- | --- | --- | --- |
| 学前启蒙 | 1 | 你比同龄人更早建立学习习惯 | 5 岁 `INT+2` |
| 重点学区房 | 2 | 你从小接触到更强的教育资源 | `MNY+2`，小学阶段高质量事件权重提升 |
| 县中黑马 | 1 | 环境一般，但你特别能卷 | 初中后 `INT` 成长事件权重上升 |
| 偏科怪才 | 1 | 数理极强，语文发挥不稳 | `INT+2`，高考稳定度下降 |
| 自律成瘾 | 2 | 你对计划表有近乎病态的执行力 | `STR+1`，关键节点 `INT` 成长提高 |
| 逢考失眠 | 0 | 平时还行，越到大考越容易崩 | 高考前 `SPR-3` |
| 班主任偏爱 | 1 | 老师愿意给你更多关注和机会 | 校内竞赛、推荐资格权重提升 |
| 家长期望过高 | 0 | 你的家总是把“别人家孩子”挂在嘴边 | `SPR-1`，但部分努力事件权重提升 |
| 竞赛体质 | 2 | 你特别适合在竞赛体系里出成绩 | 竞赛事件触发率提升，可通往保送链 |
| 艺体特长 | 1 | 你有一条不完全依赖文化课的路径 | 开启艺考 / 体育单招结局 |
| 押题圣体 | 3 | 你总能诡异地贴近考试重点 | 高考阶段额外分数加成 |
| 信息闭塞 | 0 | 你对选科、竞赛、报考规则总慢半拍 | `VOL-20` |
| 志愿军师 | 2 | 你身边有人很懂报考策略 | `VOL+35` |
| 少数民族加分 | 1 | 你在录取政策上有天然优势 | 高考结算修正加分 |
| 佛脚战神 | 1 | 平时一般，冲刺期提升极快 | 17-18 岁 `INT` 成长翻倍 |

#### 3.5.3 天赋互斥建议

- `重点学区房` 与 `县中黑马`
- `自律成瘾` 与 `重度拖延`
- `竞赛体质` 与 `全面均衡`
- `艺体特长` 与 `保送苗子`
- `志愿军师` 与 `信息闭塞`

#### 3.5.4 天赋继承建议

继承对象建议更偏“长期形成的能力”而非“出身设定”，例如：

- 可继承：自律、抗压、竞赛经验、信息意识
- 不建议继承：学区房、家庭背景、政策身份

### 3.6 阶段事件设计

#### 3.6.1 阶段划分

| 阶段 | 年龄 | 目标 | 主要事件类型 |
| --- | --- | --- | --- |
| 学前期 | 3-5 | 建立学习兴趣与家庭底色 | 启蒙、亲子互动、健康、早教 |
| 小学期 | 6-11 | 基础能力形成 | 成绩、老师评价、兴趣班、同伴关系 |
| 初中期 | 12-14 | 分流与自我认知 | 月考排名、重点班、青春期波动、竞赛初露 |
| 高一期 | 15 | 适应新环境与选科 | 分班、住校、偏科问题、社交变化 |
| 高二期 | 16 | 路线定型 | 竞赛、强基、艺考、补课、家庭压力 |
| 高三期 | 17 | 压力累积与冲刺 | 模考、失眠、逆袭、老师谈话、情绪波动 |
| 出分填报期 | 18 | 结果兑现 | 高考、估分、出分、志愿、录取 |

#### 3.6.2 每阶段重点事件包

学前期事件方向：

- 父母是否重视教育
- 是否形成阅读、专注和作息习惯
- 早教资源投入与效果偏差
- 搬家、转学、家庭结构变化

小学期事件方向：

- 第一次考高分或考砸
- 被老师夸奖、被同学排挤
- 奥数班、英语班、书法班、补习班
- “小镇做题家”意识萌芽

初中期事件方向：

- 进入重点班或普通班
- 碰到强对手后开始内卷
- 青春期分心、早恋、沉迷游戏、手机管理
- 第一次大型排名焦虑

高一期事件方向：

- 选科决策是否匹配个人优势
- 寄宿生活对精力与心态的冲击
- 发现周围天才太多后的自我怀疑
- 班主任、教练、补课老师带来的路线变化

高二期事件方向：

- 竞赛集训、强基计划、艺考培训
- 家庭经济压力爆发
- 成绩平台期
- 一次模考改变自我定位

高三期事件方向：

- 一轮复习提分、二轮瓶颈、三轮押题
- 模考超常或失常
- 熬夜与状态值消耗
- 家长、老师、同学对心态的干预
- 临近高考的崩溃或顿悟

出分填报期事件方向：

- 估分偏差
- 高考超常发挥 / 临场失误
- 志愿冲稳保策略
- 被调剂、滑档、捡漏
- 服从调剂与城市优先的价值冲突

#### 3.6.3 关键事件链建议

1. 县中逆袭链  
学前资源一般 -> 小学成绩突出 -> 初中重点班 -> 高中遇强更强 -> 高考逆袭 985 / 清北边缘

2. 竞赛保送链  
数理特长 -> 竞赛教练注意 -> 省队 / 国奖 -> 保送或强基

3. 心态崩盘链  
家长期待过高 -> 多次排名波动 -> 高三失眠 -> 临场失常 -> 复读或转轨

4. 志愿翻车链  
分数足够 -> `VOL` 不足 -> 冲得过高 -> 滑档 / 被不喜欢专业录取

5. 低分逆袭链  
分数一般 -> `VOL` 极高 -> 地域 / 专业判断正确 -> 实际结果优于同分段

## 4. 方案 2：《高三 365 天重开模拟器》冲刺版

### 4.1 项目定位

冲刺版将时间轴从“18 年成长”压缩为“高三一年冲刺”，重点表现日常选择、效率管理、压力累积和模考反馈。它更像高密度策略模拟，单局节奏更快，玩家的操作感更强，适合做传播性和复玩性都很高的副模式或独立模式。

### 4.2 核心体验

- 每回合都在“提分”和“活下去”之间做权衡。
- 平时成绩、临场发挥、精神状态三条线同时拉扯。
- 比起标准版的长线养成，冲刺版更强调局内策略和当下抉择。
- 玩家会不断尝试不同的冲刺流派，如“刷题流”“补觉流”“全科均衡流”“押题流”“玄学流”。

### 4.3 核心流程

1. 进入模式选择。
2. 选择冲刺版高三模式。
3. 选择 3 个天赋。
4. 分配初始属性或选择预设冲刺模板。
5. 从高三开学第 1 天推进到高考结束。
6. 每个周期执行“行动选择 -> 事件结算 -> 模考反馈 -> 状态变化”。
7. 到达高考日进行临场结算。
8. 出分并进入志愿填报与结局总结。

### 4.4 时间单位设计

推荐提供两种实现方式：

- 方案 A：按“周”推进，1 局共 48 到 52 周，便于控制节奏。
- 方案 B：按“天”推进，但将 7 天压缩成一个操作回合，界面仍表现为日期流逝。

若优先兼容原项目结构，建议内部仍使用 `AGE` 字段承载“周序号”或“阶段索引”，表现层再翻译成“第 X 周”。

### 4.5 属性系统

#### 4.5.1 当前属性表

| 代码 | 名称 | 类型 | 建议范围 | 含义 | 备注 |
| --- | --- | --- | --- | --- | --- |
| DAY | 冲刺日 | 当前属性 | 1-365 | 当前时间进度 | 表现层字段 |
| BAS | 基础分 | 可分配 | 350-620 | 进入高三时的学科底子 | 决定起跑线 |
| EFF | 效率 | 可分配 | 0-10 | 单位时间学习产出 | 影响所有学习行动 |
| STA | 体力 | 可分配 | 0-10 | 连续学习和熬夜的耐受能力 | 影响行动上限 |
| SAN | 心态 | 默认 5 | 0-10 | 焦虑、挫败恢复、自信心 | 影响模考波动 |
| SUP | 支持度 | 可分配 | 0-10 | 家庭、老师、金钱与信息支持 | 影响补课和志愿 |

#### 4.5.2 派生属性建议

| 代码 | 名称 | 计算逻辑建议 | 用途 |
| --- | --- | --- | --- |
| HP | 冲刺续航 | `STA + SAN - CRS系数` | 判断是否崩溃 |
| STB | 稳定度 | `EFF + SAN` | 决定模考波动 |
| BUR | 倦怠值 | 熬夜和重复刷题累计 | 触发摆烂与厌学 |
| MOCK | 模考表现 | 分阶段刷新 | 为高考结果提供参考 |
| FINAL | 高考发挥值 | 高考当天计算 | 最终录取核心 |

#### 4.5.3 结算公式建议

高考结果 `FINAL` 建议由以下部分构成：

- `BAS`
- 学习行动累计收益
- `EFF` 与 `STA` 的长期成长收益
- 模考稳定度修正
- 临场事件修正
- 天赋与特殊路线修正

推荐让 `PRED` 更稳定，`FINAL` 更戏剧化。这样玩家会对“高考当天发生了什么”更有感受。

### 4.6 行动系统

冲刺版建议新增“行动槽”概念。每周或每个回合可执行 2 到 3 个行动。

#### 4.6.1 行动分类

| 行动 | 主要收益 | 主要代价 | 设计意义 |
| --- | --- | --- | --- |
| 刷题 | `BAS/PRED` 提升 | `STA-1`，`CRS+2` | 稳定基本收益 |
| 补课 | `PRED` 快速提升 | `SUP-1` 或资源消耗 | 高成本高回报 |
| 复盘错题 | `STB` 提升 | 收益慢 | 提高稳定度 |
| 睡觉 | `STA+2`，`SAN+1` | 当周提分变慢 | 恢复性行动 |
| 运动 | `STA+1`，`SAN+1` | 占用时间 | 防崩盘 |
| 摸鱼 | `SAN+2` | `PRED` 下降 | 有时是必要止损 |
| 求神拜佛 | 小概率高收益 | 大概率无事发生 | 魔性整活内容 |
| 和老师沟通 | `SUP` 或 `VOL` 提升 | 触发特定事件 | 打开信息路线 |
| 和家长沟通 | 降压或加压 | 看事件结果 | 叙事性强 |
| 查志愿 | `VOL+` | 仅后期可用 | 志愿线核心 |

### 4.8 阶段事件设计

#### 4.8.1 阶段划分

| 阶段 | 时间 | 目标 | 主要事件 |
| --- | --- | --- | --- |
| 适应期 | 1-60 天 | 进入高三节奏 | 开学分班、作息重构、第一次周测 |
| 提升期 | 61-180 天 | 形成稳定提分节奏 | 一轮复习、补课、偏科补洞 |
| 瓶颈期 | 181-260 天 | 面对平台期和心态波动 | 二轮复习、排名焦虑、家长期待 |
| 冲刺期 | 261-330 天 | 决定上限与稳定度 | 三轮押题、名师点拨、失眠焦虑 |
| 临场期 | 331-365 天 | 把分数兑现 | 考前状态、高考当天、估分和出分 |

#### 4.8.2 重点事件包

适应期：

- 高三第一次考试被打醒
- 老师重新排座位
- 手机上交与作息整顿
- 发现自己和尖子生差距巨大

提升期：

- 某一科突然开窍
- 补课班值不值
- 同桌带动学习节奏
- 你开始建立错题体系

瓶颈期：

- 努力没有立刻反馈
- 模考排名反复横跳
- 家长情绪传导
- 同学保送 / 出国带来的心态波动

冲刺期：

- 一百天誓师
- 押题卷神准 / 神坑
- 连续熬夜后的身体警报
- 老师一句话改变你最后的策略

临场期：

- 考前失眠
- 考场座位、天气、身体状态
- 语文作文押中
- 数学前半场崩住、后半场找回状态
- 出分瞬间与志愿填报

#### 4.8.3 事件链建议

1. 逆袭链  
开局基础一般 -> 行动节奏稳定 -> 最后一百天爆发 -> 高考超常

2. 倦怠链  
过度刷题 -> `BUR` 飙升 -> 学习厌恶 -> 模考下滑 -> 冲刺失速

3. 玄学链  
求签 -> 巧合事件 -> 押题成功 / 心态稳定 -> 隐藏结局

4. 老师拯救链  
沟通 -> 获得针对性建议 -> 找到提分短板 -> 高考提升

5. 志愿二次博弈链  
出分不算顶尖 -> `VOL` 高 -> 决策正确 -> 结果优于高分低志愿情报玩家

## 5. 两个方案的取舍建议

### 5.1 方案 1 适合什么

- 更贴近原作结构，改造成本低。
- 更适合做主模式和长期内容扩展。
- 更适合承载“县中逆袭、竞赛保送、家庭影响”等叙事。

### 5.2 方案 2 适合什么

- 更强的操作感和传播性。
- 更适合短视频、直播和反复挑战。
- 更适合作为“高考主题活动模式”或独立副模式。

### 5.3 推荐落地顺序

1. 先做方案 1，尽量复用现有年龄推进、事件表和结局框架。
2. 方案 1 稳定后，再做方案 2 作为高压冲刺副模式。
3. 两个方案共享天赋素材、结局标签和成就体系，降低内容生产成本。

## 6. 下一步落地建议

- 先各写一版最小可玩内容表：每个方案 20 个天赋、60 个事件、8 个结局。
- 先验证 3 个重点循环是否成立：标准版的阶段成长感、冲刺版的回合决策感、两者的重开欲。
- 若要快速进到实现阶段，优先把 `VOL`、`HSCR`、`PRED`、`CRS` 这几个新增指标定死，再反推事件和天赋数值。
