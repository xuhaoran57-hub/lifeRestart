# 高考重开模拟器 MVP 内容表

本文档提供两套模式的最小可玩内容表，目标是让策划可以直接按表录入 Excel 并开始首轮原型验证。

建议首轮验证只追求三件事：

- 能顺畅跑完 1 局
- 能明显感知不同开局的差异
- 能稳定产出 8 类以上结局

## 3. MVP 验证重点

### 3.1 标准版先验证什么

- `重点学区房`、`县中黑马`、`志愿军师` 三类开局是否能明显走出不同轨迹。
- `高考超常`、`临场失常`、`志愿翻车` 三个节点能否真正改变结局层级。
- `竞赛保送` 和 `志愿鬼才` 两条非纯分数路线是否足够有存在感。

### 3.2 冲刺版先验证什么

- `刷题 / 复盘 / 睡觉` 三个基础行动是否形成明确取舍。
- `平台期 -> 调整 -> 临场` 这条回合反馈链是否足够上瘾。
- `模考很高但高考失手` 与 `平时一般但最后爆发` 是否都能稳定出现。

### 3.3 首轮不建议急着做的内容

- 名人角色
- 成就系统全量扩展
- 特殊主题皮肤
- 超长剧情链
- 过多地域或专业细分

先把这一版跑通，再扩到正式量产内容会更稳。
